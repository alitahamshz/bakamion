# پروژه مدیریت رکوردها

پروژه با React، TypeScript و Vite ساخته شده و برای نمایش و مدیریت رکوردهاست.

## اجرا

به Node.js (نسخه LTS) و npm نیاز است. در پوشه پروژه این دستورها را اجرا کنید:

```bash
npm install
npm run dev
```

فایل `.env` اختیاری است؛ اگر نیاز به تغییر آدرس API باشد، ابتدا `.env.example` را با نام `.env` کپی و مقدار `VITE_API_BASE_URL` را تغییر دهید.

بعد از اجرا، آدرس نمایش پروژه در ترمینال نشان داده می‌شود؛ معمولاً `http://localhost:5173` است.

## ساخت نسخه نهایی

```bash
npm run build
```

فایل‌های خروجی در پوشه `dist` قرار می‌گیرند. برای دیدن نسخه نهایی روی سیستم محلی:

```bash
npm run preview
```

## چند دستور مفید

```bash
npm run lint
npm run format:check
npm run format
```

## داده‌ها

داده‌های اولیه از `https://api.bakamion.ir/task-front` دریافت می‌شوند. تغییرات ایجاد، ویرایش و حذف در Local Storage مرورگر ذخیره می‌شوند؛ بنابراین بعد از رفرش صفحه باقی می‌مانند، اما به همان مرورگر محدود هستند.

برای دریافت دوباره داده‌های اولیه، کلید `app-records` را از Local Storage مرورگر پاک و صفحه را رفرش کنید.
